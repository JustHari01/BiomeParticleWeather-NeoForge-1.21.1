# Biome Particle Weather — NeoForge Port

Unofficial NeoForge port of **Biome Particle Weather / Impactful Weather** for Minecraft 1.21.1.

The original project is by [shadowmaster435](https://github.com/shadowmaster435/Impactful_Weather) (CurseForge: shadowmaster404). This repository adapts the project for NeoForge 1.21.1; it is separate from, and is not endorsed by, the original project. Please send NeoForge-port support requests to the [Hari Community Discord](https://discord.gg/atKQ3KrAK3), not the original issue tracker.

## Build

Requires Java 21. From the repository root, run:

```powershell
.\gradlew.bat build
```

The built mod is written to `build/libs/`.
